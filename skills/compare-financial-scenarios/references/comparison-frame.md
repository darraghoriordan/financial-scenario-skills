# Neutral scenario comparison frame

Choose measures that answer the user's question and exist in both structured results.

## Input differences

- Start/end date and first-year duration
- Income and expense amount, frequency, owner, and timing
- Purchases, sales, financing, and debt terms
- Account type, opening balance, access, and user-selected cashflow rules
- Growth, yield, fees, inflation, tax, and money-value settings
- Milestones and event dependencies

## Output differences

- First engine-defined cashflow shortfall and unmet amount
- Net worth, liquid balance, debt, and accessible retirement balance at matching dates
- Total income, expenses, tax, fees, interest, and contributions over a matching period
- Asset purchase/sale proceeds and debt payoff timing
- Nominal and present values when both use the same basis

## Presentation rules

- Label absolute values and deltas with currency and date.
- Keep signs consistent: define whether a positive delta favors Scenario A mathematically, without calling it preferable.
- Show both values beside each delta.
- Avoid composite scores and color semantics that imply a recommendation.
- State mismatched assumptions next to the affected metric, not only in a footnote.
